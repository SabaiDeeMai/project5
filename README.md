# README

## Описание проекта
Данный проект содержит несколько функций для работы с данными, такими как транзакции, номера карт и счета. Функции позволяют фильтровать, сортировать данные и маскировать чувствительную информацию.

## Установка
Проект не требует дополнительной установки, так как написан на Python и использует стандартные функции языка.

## Описание функций

### `filter_by_state(data, state='EXECUTED')`
Функция фильтрует список словарей по значению ключа `state`. Она принимает список словарей и проверяет каждый элемент на соответствие указанному состоянию.

**Параметры:**
- `data` (list) — список словарей с транзакциями.
- `state` (str, по умолчанию 'EXECUTED') — состояние, по которому выполняется фильтрация. Например, `EXECUTED`, `CANCELED` и т. д.

**Возвращает:**
- Новый список словарей, содержащий только записи с указанным состоянием.

### `sort_by_date(data, descending=True)`
Функция сортирует список словарей по значению ключа `date`.

**Параметры:**
- `data` (list) — список словарей с транзакциями.
- `descending` (bool, по умолчанию `True`) — порядок сортировки (по убыванию).

**Возвращает:**
- Новый отсортированный список словарей.

### `get_mask_card_number(card_number: str) -> str`
Функция принимает на вход номер карты и возвращает его маску. Первые 4 цифры и последние 4 цифры остаются видимыми, а остальные заменяются звездочками.

**Параметры:**
- `card_number` (str) — номер карты, который необходимо замаскировать.

**Возвращает:**
- Строку с маскированным номером карты, например: `"1234 56** **** 7890"`.

### `get_mask_account(account_number: str) -> str`
Функция принимает на вход номер счета и возвращает его маску. Маскируются все цифры, кроме последних 4.

**Параметры:**
- `account_number` (str) — номер счета, который необходимо замаскировать.

**Возвращает:**
- Строку с маскированным номером счета, например: `"** 7890"`.

### `mask_account_card(account_info: str) -> str`
Функция возвращает строку с замаскированным номером карты или счета, в зависимости от длины входного значения. Если длина строки равна 16, то это номер карты, если меньше — это номер счета.

**Параметры:**
- `account_info` (str) — строка, содержащая номер карты или счета.

**Возвращает:**
- Строку с замаскированным номером карты или счета.

### `get_date(date: str) -> str`
Функция принимает строку в формате 'YYYY-MM-DDTHH:MM:SS.ssssss' и возвращает дату в формате 'ДД.ММ.ГГГГ'.

**Параметры:**
- `date` (str) — строка с датой в формате 'YYYY-MM-DDTHH:MM:SS.ssssss'.

**Возвращает:**
- Строку с датой в формате 'ДД.ММ.ГГГГ'.
